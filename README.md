# Internet Speed Checker

Небольшой консольный скрипт на Python, который 10 раз последовательно скачивает содержимое указанного HTTP(S)-адреса и рассчитывает среднее время запроса, общий объём данных и среднюю скорость загрузки.

## Требования

- Python 3.9 или новее.
- Сторонние библиотеки не нужны: используются только модули стандартной библиотеки Python.

## Запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/<ваш-логин>/internet-speed-checker.git
   cd internet-speed-checker
   ```

2. Запустите скрипт, передав полный URL ресурса:

   ```bash
   python main.py "https://example.com/image.jpg"
   ```

   В Windows также можно использовать команду `py`:

   ```powershell
   py main.py "https://example.com/image.jpg"
   ```
   
   Проверенная ссылка
   ```bash
   python main.py "https://speedtest.selectel.ru/10MB"    
   ```

Вместо примера укажите адрес файла или другого ресурса, который хотите скачать. Скрипт выполнит ровно 10 GET-запросов по очереди и дождётся полного чтения тела каждого ответа. Для каждого запроса используется тайм-аут 30 секунд.

## Что выводится

- среднее время одного запроса — в секундах (`с`);
- общее время выполнения загрузок — в секундах (`с`);
- общий объём скачанных тел ответов — в мегабайтах (`MB`);
- средняя скорость скачивания — в мегабитах в секунду (`Мбит/с`, или `Mbps`).

Используются десятичные единицы: `1 MB = 1 000 000 байт`, `1 Мбит = 1 000 000 бит`. Скорость рассчитывается как общий объём скачанных данных в битах, делённый на общее время всех 10 загрузок в секундах. HTTP-заголовки и служебный сетевой трафик в объём не входят.
